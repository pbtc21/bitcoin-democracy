How It Works

Deposit Bitcoin. Get voting power. Elect representatives. Govern the treasury.

💰

Deposit

Deposit sBTC into the treasury and receive CityBTC governance tokens

🗳

Delegate

Delegate your voting power to trusted representatives

🏆

Elect

Top 30 vote-getters become trustees after 24h challenge period

⚖

Govern

Trustees hire a coordinator who manages daily operations

Truly Unstoppable

Built to resist government shutdown. Once deployed, no one can stop it.

🔥

Burned Admin Keys

After setup, admin keys are permanently destroyed by sending to a burn address. No backdoors, no recovery.

⛔

No Pause Function

Unlike other DeFi protocols, there's no pause button. Deposits and withdrawals always work.

🔗

No External Dependencies

No yield protocols that could freeze funds. Pure on-chain logic with no external kill switches.

👥

Permissionless Execution

Anyone can trigger governance actions once conditions are met. No gatekeepers.

🔒

Challenge Periods

24-hour delay on elections allows community to verify results before finalization.

🔄

Recall Mechanism

Token holders can recall the board with 33% stake, resetting elections if needed.

Trust Model

One trust assumption. Everything else is trustless code.

✅

Trustless

Elections: On-chain, verifiable, challengeable
Governance: Transparent voting, permissionless execution
Treasury: Immutable rules, no admin override
Tokens: Fixed supply mechanics, no hidden minting

🔐

Trust Required

sBTC Signers: 15 entities custody the Bitcoin backing sBTC. This is the only external trust assumption. If sBTC works, Bitcoin Democracy works.
